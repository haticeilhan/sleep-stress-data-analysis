# Sleep, Stress, and Sleep Quality: A Data Analysis Project

## Overview

This project explores relationships between sleep duration, sleep quality, stress levels, and selected health indicators using Python.

The goal is to identify patterns in the dataset through exploratory data analysis (EDA), data visualization, and correlation analysis.

## Research Questions

- How is sleep duration distributed across participants?
- Is sleep duration associated with reported sleep quality?
- How are stress levels related to sleep and other health indicators?

## Dataset

**Sleep Health and Lifestyle Dataset**

Source: [Kaggle — Sleep Health and Lifestyle Dataset](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset)

The dataset contains variables such as sleep duration, sleep quality, stress level, physical activity, heart rate, and sleep disorders.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Methods

1. Data loading and inspection
2. Missing-value and duplicate checks
3. Descriptive statistics
4. Sleep duration distribution visualization
5. Sleep duration versus sleep quality analysis
6. Correlation analysis between selected health variables

## Limitations

This dataset contains reported sleep-quality and lifestyle measures, but it does not include direct cognitive test scores. Therefore, this project does not directly measure cognitive performance or establish causal relationships.

Correlation results should be interpreted as associations, not evidence of causation.
